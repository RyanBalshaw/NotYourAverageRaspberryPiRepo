### Strava Latest Activity Map Plotter

A Raspberry Pi project to visualise your latest activities from Strava. This program fetches your recent Strava running data, generates a map plot, and sets up a visual kiosk display.

### Initial Setup

Perform these steps to set up the environment:

1. Clone the repository to your Raspberry Pi.
2. Ensure Python 3 is installed.
3. Create a virtual environment using `virtualenv`: `python -m venv /path/to/new/virtual/environment`
4. Activate the virtual environment: `source /path/to/new/virtual/environment/bin/activate`
5. Install the required Python packages by running `python -m pip install -r requirements.txt`.
6. Configure your Strava API credentials and save them in an 'user_information.env' file.

### Usage

Run the visualiser Python script to fetch the latest Strava data, generate a plot, and save it as an image.
```bash
python main.py
```

### Automation

- Setup a cron job to update the display regularly:

  Open the crontab editor:
  ```
  crontab -e
  ```

  Add this line to run the script every hour:
  ```
  0 * * * * /path/to/tmp/run_strava_script.sh
  ```

### Display Configuration

To display the generated plot via a webpage on startup:

1. Install a lightweight browser like Chromium if you haven't already:
   ```
   sudo apt-get install chromium-browser
   ```

2. Utilise the provided startup script to launch the browser in kiosk mode and display the plot:
   ```
   /path/to/tmp/launch_strava_kiosk.sh
   ```

3. Make the browser launch on startup:

   Create a `.desktop` file in `~/.config/autostart/`:
   ```
   mkdir -p ~/.config/autostart
   nano ~/.config/autostart/strava_kiosk.desktop
   ```

   Add the following content:
   ```
   [Desktop Entry]
   Type=Application
   Name=Strava Kiosk
   Exec=/path/to/tmp/launch_strava_kiosk.sh
   ```
